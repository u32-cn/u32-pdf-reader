01

为什么做这个阅读器

常给孩子看英文自然拼读（Phonics）的 PDF 绘本，其中不少 PDF 自带朗读音频。但实测下来，除了 Adobe 家的阅读器，其他几乎所有工具都播不出声音——福昕、各类小众 PDF 阅读器，甚至浏览器内置的 PDF 查看器。

这个功能明明很有用，却一直缺一个轻量的实现。过去没有 AI，独立开发成本太高；现在条件成熟，就动手做了这一个。

「UI 说不上好看，但功能是真的能用。」

不想用 Adobe 的原因很简单：安装包太大、UI 太复杂。需要的只是一个能看、能简单批注、能播放内嵌音频的小型 PDF 阅读器。

所以它全本地运行：不联网、不上传，也不修改你的原 PDF。

02

核心功能

01 / 阅读

连续滚动，只画看得见的那几页

pdf.js 渲染管线，接近 700px 才画、离得 2600px 就释放位图。

  • 每页 canvas 之上叠一层透明文本层：文字可选、可复制，也是高亮与下划线的前提
  • 页码跳转、Ctrl+滚轮 / Ctrl+± 缩放、Ctrl+0 适应宽度，侧栏可折叠
  • 拖拽 PDF 到窗口直接打开，或 Ctrl+O
02 / 批注

五种工具，选中即标注

指针 · 高亮 · 下划线 · 便签 · 文字，键盘 V H U N T 直接切换。

  • 指针模式下选中文字即浮出工具条，一步打高亮 / 下划线；也可先按 H / U 再选
  • 便签与文字进放置模式（十字光标），点页面任意位置就地弹窗输入；点已有批注可重新编辑，内容清空即删除
  • 侧栏「批注」列出全部批注，点击跳转、可删除；「缩略图」栏切换页面
  • 批注写进旁注文件 <同名>.annotations.json，归一化坐标，换缩放 / 换屏不漂移
03 / 内嵌音频

点音频图标，播放条就在它下面

这是做这个阅读器的起点：解析 PDF 的 Sound 注解，把原始声音流取出来播。

  • 播放条锚定在图标下方浮出（不是固定底栏），多音频互斥播放：点第二个图标，播放条迁移过去并切换音源
  • 进度条可拖拽、倍速 0.5–2x、可暂停，不用从头听
  • 靠近页面右缘向左展开、靠近底部自动翻到图标上方，始终钳制在页面内
  • 关闭方式：× / Esc / 再点同一个图标

04

已知限制（先说清楚）

LIMIT单窗口、单文档，没有标签页
LIMIT批注只存旁注 JSON，不写回 PDF；换机器需连 .annotations.json 一起拷
LIMIT只提取 Sound 注解里的声音流，RichMedia / 视频注解暂不处理
LIMIT只做浅色主题（设计 token 已按「换 token 即换肤」组织，暗色未实现）
